# Hamza — Portfolio

A bilingual Arabic/English personal portfolio for Hamza, built as a static HTML page.

## Preview

Once GitHub Pages is enabled, the site will be available at:

https://elshorihy.github.io/Portfolio-/

## Publish with GitHub Pages

1. Open **Settings → Pages** in this repository.
2. Under **Build and deployment**, select **Deploy from a branch**.
3. Choose branch **main** and folder **/(root)**.
4. Save. The published entry point is `index.html`.

## Notes

- The page is a static site; no build command or package installation is required.
- Styling and animation libraries are loaded from public CDNs.
- The repository includes `.nojekyll` so GitHub Pages serves the site without Jekyll processing.
